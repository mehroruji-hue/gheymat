# قیمت (نسخه‌ی ۰.۱)

وب‌اپ نصب‌شدنی (PWA): **قیمت رو بخون، تخفیف رو حساب کن**. [ایده‌ی ۸](../ideas/08-gheymat.md) رو ببینید.

## چی دارد
- **خواندن مبلغ از دوربین زنده**، بدون عکس گرفتن و بدون ارسال هیچ تصویری (همه‌ی پردازش روی خود گوشی)
- **نمایش درشت + همان مبلغ با حروف** («چهارصد و پنجاه هزار تومان»)
- **ریال و تومان** همزمان، با دکمه‌ی جابه‌جایی
- **تخفیف:** درصدهای آماده، امکان دو تخفیف پشت‌سرهم، نمایش قیمت نهایی و مقدار صرفه‌جویی
- **خواندن با صدا** (اختیاری، با دکمه)
- صفحه‌کلید درشت با دکمه‌ی «۰۰۰»، کار آفلاین، حالت روشن و تاریک

## خواندن ارقام فارسی
Tesseract ارقام فارسی را قابل اتکا نمی‌خواند (اطمینان ۴۶ تا ۵۴٪ و عدد غلط). برای همین `js/fadigits.js` نوشته شد:
آستانه‌ی اوتسو ← جدا کردن اجزای به‌هم‌پیوسته ← یکسان‌سازی اندازه ← مقایسه با الگوهایی که همان لحظه از فونت‌های موجود ساخته می‌شوند.
در تست: هر ده رقم، هر دو جداکننده (٬ و ,) و حتی نوشته‌ی سفید روی زمینه‌ی تیره، همه درست خوانده شدند، با ۸۹ تا ۹۵٪ اطمینان و حدود **۴ میلی‌ثانیه** برای هر فریم، بدون هیچ دانلودی.

دوربین اول فارسی را امتحان می‌کند؛ اگر پنج بار پشت‌سرهم چیزی پیدا نشد، موتور لاتین را بارگذاری می‌کند.

**محافظ‌ها:** زیر اطمینان ۶۸٪ (فارسی) و ۷۰٪ (لاتین) هیچ عددی پیشنهاد نمی‌شود، و عدد خوانده‌شده همیشه نیاز به **تأیید کاربر** دارد.

## اجرا روی کامپیوتر
```bash
python -m http.server 5176 -d gheymat
```

## ساختار
| فایل | کار |
|---|---|
| `js/money.js` | تبدیل عدد به حروف فارسی، ریال و تومان، محاسبه‌ی تخفیف |
| `js/scan.js` | دوربین، برش وسط کادر، بهبود تصویر، و انتخاب بین دو موتور |
| `js/fadigits.js` | تشخیص‌دهنده‌ی ارقام فارسی، بدون کتابخانه و بدون اینترنت |
| `js/app.js` | رابط کاربری، صفحه‌کلید، صدا |
