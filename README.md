# قیمت (نسخه‌ی ۰.۱)

وب‌اپ نصب‌شدنی (PWA): **قیمت رو بخون، تخفیف رو حساب کن**. [ایده‌ی ۸](../ideas/08-gheymat.md) رو ببینید.

## چی دارد
- **خواندن مبلغ از دوربین زنده**، بدون عکس گرفتن و بدون ارسال هیچ تصویری (همه‌ی پردازش روی خود گوشی)
- **نمایش درشت + همان مبلغ با حروف** («چهارصد و پنجاه هزار تومان»)
- **ریال و تومان** همزمان، با دکمه‌ی جابه‌جایی
- **تخفیف:** درصدهای آماده، امکان دو تخفیف پشت‌سرهم، نمایش قیمت نهایی و مقدار صرفه‌جویی
- **خواندن با صدا** (اختیاری، با دکمه)
- صفحه‌کلید درشت با دکمه‌ی «۰۰۰»، کار آفلاین، حالت روشن و تاریک

## محدودیت شناخته‌شده
دوربین فعلاً فقط **ارقام لاتین** (123) را قابل اتکا می‌خواند. ارقام فارسی در تست، هم با مدل انگلیسی و هم با مدل فارسی، **غلط** خوانده شدند. برای همین:
- این محدودیت در خود اپ به کاربر گفته می‌شود
- زیر اطمینان ۷۰٪ هیچ عددی پیشنهاد نمی‌شود
- عدد خوانده‌شده همیشه نیاز به **تأیید کاربر** دارد

## اجرا روی کامپیوتر
```bash
python -m http.server 5176 -d gheymat
```
